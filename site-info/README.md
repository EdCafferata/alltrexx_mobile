# Site-info — AllTreXX

Alle info die voor AllTreXX **via een URL** wordt verstrekt (store-listing, support/privacy/marketing),
op één plek en versiebeheerd. Conventie voor alle EdCafferata-app-repo's (map `site-info/`).

## De 4 pagina's (5 talen: NL root + en/ de/ fr/ es/)
`index.html` (marketing), `support.html`, `privacy.html`, `voorwaarden.html`.

**LIVE** op https://cafferata.info/alltrexx/ sinds 18 okt 2026 (gedeployed naar de NAS-webroot
`/Volumes/web/alltrexx/`; gestyled met de gedeelde IT Crowd-stijl `cafferata.info/assets/style.css`).
Legal: NL is juridisch leidend; DE/FR/ES zijn vertalingen (met vertaalnotitie).

## Onderhoud
Bij een nieuwe store-indiening deze pagina's nalopen en de store-listing-URL's hierheen laten wijzen.
Gegenereerd met het gedeelde generatie-script (zie oc-consent/site-info + scratchpad gen_lib.py).
